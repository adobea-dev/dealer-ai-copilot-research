# Dealer AI Copilot 2.0

Research project investigating whether agentic analytics can reduce the
technical expertise required to derive decision-ready insights from
structured business data compared with conventional Text-to-SQL systems.

## Current Phase

Synthetic dealer analytics dataset design and validation.

## Research Pipeline

1. Design synthetic data-generating process
2. Generate reproducible dataset
3. Validate data integrity
4. Conduct exploratory data analysis
5. Freeze research dataset
6. Build PostgreSQL experimental database
7. Build Text-to-SQL baseline
8. Build natural-language explanation baseline
9. Build agentic analytics system using Google ADK
10. Run system and human evaluations
